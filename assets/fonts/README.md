Self-hosted Google Fonts (latin subset, woff2), all under the SIL Open Font License 1.1.

| File | Family | Used for |
|---|---|---|
| pixelify-sans-400/700.woff2 | Pixelify Sans | title, HUD, small labels (pixel font) |
| instrument-serif-italic.woff2 | Instrument Serif Italic | taglines (elegant italic serif) |
| shrikhand.woff2 | Shrikhand | how-to-play lines (groovy chunky display) |
| dm-serif-display.woff2 | DM Serif Display | song titles (bold serif) |

Source: the @fontsource npm packages, which repackage the Google Fonts files.
To swap a font, replace the file and update the @font-face rules at the top of css/style.css.
